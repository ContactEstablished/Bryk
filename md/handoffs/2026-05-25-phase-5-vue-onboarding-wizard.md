## Manual smoke status

Not fully verified in this environment. Because the full Phase 5 exit checklist requires browser/API interaction against a running local API and database, `ROADMAP.md` was not marked complete.

Smoke checklist still to perform before declaring Phase 5 complete:

1. Full happy path from `/onboarding`:
   - Required step creates/updates the Athlete fields.
   - Recommended step creates/updates at least one sport profile.
   - Goals step appends at least one Goal or Event.
2. Reload/resume matrix:
   - No completion flags true → Required step active.
   - Required only → Recommended step active; Goals locked.
   - Required + Recommended → Goals step active.
   - All three true → done state.
3. Server validation UI behavior:
   - A backend validation failure surfaces as field-level vee-validate errors when mapped.
   - Unmapped validation messages surface as a sane global error.
4. Triathlon payload behavior:
   - Non-triathlon events submit `triathlonDistance: null` and `customDistanceName: null`.
   - Triathlon Custom distance submits `customDistanceName` only when applicable.
